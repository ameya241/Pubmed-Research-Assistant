<H1>🧠 PubMed Research Assistant</H1>
<h3>Medical Research Paper Q&A System (RAG)</h3>
<h2>📌 About</h2>

This project is a Retrieval-Augmented Generation (RAG) system that allows users to ask questions about medical research papers and get contextual answers with citations.

Instead of building another basic “chat with PDF” demo, I wanted to work on a real-world use case — searching and understanding complex medical research papers from PubMed.

<H2>🚀 What It Does</H2>

<br>🔎 Searches medical research papers</br>
<br>📚 Retrieves the most relevant sections</br>
<br>🤖 Generates AI-based answers</br>
<br>🧾 Provides citations from original research</br>
<br>🌐 Deployed and shareable</br>

<H2>🛠 Tech Stack</H2>

<br>Python</br>
<br>Streamlit</br>
<br>LLM API</br>
<br>Embeddings Model</br>
<br>Vector Database (FAISS / ChromaDB)</br>
<br>PubMed Dataset</br>

<H2>💡 What I Learned </H2>

How RAG works end-to-end

How embeddings + vector search improve accuracy

Importance of chunking and prompt design

How to structure and deploy a complete AI pipeline
